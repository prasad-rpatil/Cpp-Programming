# C++ Programming

This repository contains my C++ programming practice programs created while learning the fundamentals of the C++ language.

## 📚 Topics Covered

- Basic Syntax
- Input and Output
- Variables and Data Types
- Operators
- Conditional Statements (`if`, `if-else`, `switch`)
- Loops (`for`, `while`, `do-while`)
- Functions
- Arrays
- Strings
- Pointers
- References
- Structures
- Classes and Objects
- Constructors and Destructors
- Inheritance
- Polymorphism
- Recursion
- File Handling
- Standard Template Library (STL)
- Searching Algorithms
- Sorting Algorithms
- Pattern Programs
- Number Programs
- Problem Solving

## 🎯 Purpose

The purpose of this repository is to:

- Learn C++ programming from basics to advanced concepts.
- Improve problem-solving skills.
- Practice object-oriented programming (OOP).
- Build a strong foundation for Data Structures and Algorithms (DSA).
- Track my learning progress.

## 🛠️ Technologies Used

- C++
